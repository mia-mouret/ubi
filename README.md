# Un salaire à vie

Une plaquette pour un salaire versé à chaque personne vivante en France, de la naissance à la mort, financé en redirigeant retraites, chômage, allocations, niches fiscales et aides aux entreprises. Le simulateur recalcule le montant selon les coupes choisies.

En ligne : https://mia-mouret.github.io/ubi/
